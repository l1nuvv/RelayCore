# G-019 — checkpoint E: самостоятельный проход

Статус: G-019 принята автором 2026-10-10 (`done`), с замечанием о пустоте
уровня по декорациям и наполнению. Независимые наблюдения по checkpoint E
не получены. Этот протокол разворачивает
пункты E из [brief главы](../PROJECT_PLAN.md#решение-автора--полноценная-игровая-глава-2026-10-09);
[карточка G-019](../tickets/G-019.md#g-019--полноценная-глава-связный-маршрут-угроза-и-задача)
владеет scope и статусом.

## Запуск и сохранения

CLion: **RelayCore — G-019 Playtest**, профиль `msvc-dev`; в меню выбрать
**Контур сдерживания — G-019** и **Начать прохождение**. Конфигурация задаёт
`RELAYCORE_USER_DATA_ROOT=$PROJECT_DIR$/build/g019/player-e`: progress и
player settings пишутся только в этот отдельный профиль. Обычная **RelayCore —
Play** использует прежний пользовательский каталог. Не удалять, не копировать
поверх и не сбрасывать существующий `progress.toml`.

Для запуска из PowerShell, из корня проекта:

```powershell
$taskStart = [System.Diagnostics.ProcessStartInfo]::new()
$taskStart.FileName = (Resolve-Path build/msvc-dev/src/relaygame/RelayCore.exe).Path
$taskStart.WorkingDirectory = (Resolve-Path build/msvc-dev/src/relaygame).Path
$taskStart.UseShellExecute = $false
$taskStart.Environment['RELAYCORE_ASSET_ROOT'] = (Resolve-Path build/msvc-dev/src/relaygame/assets).Path
$taskStart.Environment['RELAYCORE_USER_DATA_ROOT'] = Join-Path (Get-Location).Path 'build/g019/player-e'
[System.Diagnostics.Process]::Start($taskStart) | Out-Null
```

Повторный запуск с тем же профилем сохраняет Continue. Для другого участника
указать другой новый абсолютный каталог; не удалять первый. Относительный или
пустой override завершается ошибкой, без возврата к пользовательскому профилю.
Логи двигателя используют прежний каталог логов; override относится к игре,
не к системе логирования. F11/editor не входит в этот проход.

## Короткий brief игроку

Выберите «Контур сдерживания — G-019». Пройдите главу до завершения, используя
указатели, HUD и доступные взаимодействия. Исследуйте так, как играли бы обычно;
можно бегать. Играйте со звуком. Если непонятно, что делать, проговаривайте своё
предположение. Наблюдатель не объясняет решения.

Управление: WASD, мышь, Shift — бег, Space — прыжок, E — взаимодействие,
ЛКМ — огонь, 1/2 — оружие, F — фонарь, Esc — меню/пауза.

## Запись наблюдателю

Не показывать игроку карту, технический маршрут, тесты и решения из roadmap.
Отделить авторский повтор от первого независимого прохода. Любую подсказку
записать с временем и точным содержанием; после подсказки самостоятельность
оставшейся части нельзя переносить на весь проход.

Зафиксировать фактически запущенные executable/source/staged assets и их SHA256; `build/g019/checkpoint-e-manifest.json` относится к сохранённой подготовке и должен сверяться с текущими файлами, а не использоваться как доказательство новой сборки. Записать
имя участника, знакомство с картой, дату/время, разрешение, SDR/HDR, звук и
устройство вывода. Не менять модель/карту/баланс между выходом и Continue.

| Событие, в порядке фактического прохода | Время от старта | Наблюдение |
| --- | --- | --- |
| Старт управления | | |
| Первое понимание цели | | Слова игрока, ориентир |
| Каждая новая зона/возвращение | | Выбранный путь и причина |
| Каждая встреча | | Позиция, оружие, укрытие, действие врага, изменившее решение |
| Каждое действие с оборудованием | | Что ожидал и что заметил после |
| Затруднение/потеря маршрута | | Длительность, предположение, вмешательство |
| Смерть/retry | | Причина, потерянное время, что сохранилось |
| Выход в меню и закрытие приложения | | После первого существенного изменения мира, в безопасный момент |
| Повторный запуск → Continue | | Что восстановилось, есть ли повторная работа |
| Завершение главы | | |

Время: полное от старта до завершения, активное управление, отдельно паузы,
перезапуск и вмешательства. Отметить использование sprint. Не растягивать
проход ожиданием до 20–30 минут и не пересчитывать simulation ticks в playtime.

После прохода записать: три главных затруднения; что было интересно/скучно;
понятность цели и изменений мира; отличались ли роли врагов и причины выбора
оружия; читаемость опасного действия Хранителя; заметность/полезность звука;
оценку материалов и силуэта в движении. Авторская оценка art и независимая
gameplay acceptance — отдельные результаты.

## Результат

**Авторская приёмка, 2026-10-10:** «G019 принял, все ок. единственное что
уровень пустой по декорациям и наполнению». G-019 закрыта как `done` по
явной приёмке автора. Замечание о декорациях и наполнении записано для
следующего прохода по окружению главы.

Сборка и условия прохода, длительность, звук, Continue/retry и подробные
наблюдения не сообщены. Независимый первый проход и target 20–30 минут
**не подтверждены измерением**. Таблица выше остаётся незаполненной;
scripted progression, inspector, captures и automated lifecycle устанавливают
только соответствующие технические факты. Общая авторская приёмка G-019
не закрывает отдельные VIS/IMG/G-010 и внешние gates.
