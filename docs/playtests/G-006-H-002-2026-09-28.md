28 сентября 2026. Основание: автор принял улучшение выстрела/турели словами «уже лучше» и поручил следующий крупный блок плана. Это не отдельная приёмка всех критериев G-003–G-005.

## Условия измерения — до запуска

Локальная машина: AMD Ryzen 7 3700X, NVIDIA GeForce RTX 4060 Ti, драйвер Windows 32.0.15.9649. Контрольный бюджет — 16,67 мс (60 кадров/с) при 1280×720, VSync off, RelWithDebInfo, legacy_gamma, текущие authored lighting/shadows. Это контрольная конфигурация, не заявленные минимальные системные требования.

`relaycore_power_restoration_graphics --profile-views` измеряет шесть видов основного эпизода: вход до/после питания, резервный узел, фильтрационную, насосную после охлаждения и обратный проход. На вид: 20 прогревочных и 180 измеряемых кадров с небольшим движением камеры. Сохраняются Tracy-зоны/plots, CPU submission и время до `glFinish` (включая ожидание завершения GPU). Нет swap/present/VSync и обычного игрового update; это ограниченный graphics baseline, не длительность кадра полного прохождения. Повторяемость задаётся фиксированными видами и состояниями. HUD, меню, загрузки и редактор измерением видов не охвачены.

Полный игровой Tracy-маршрут, субъективное прослушивание, независимые игроки и другой ПК остаются отдельной приёмкой. Никакой оптимизации по предположению не выполняется.

Тесты сохраняют проверки освещения до/после, стабильности тени при малом движении камеры, фонаря и восьми local lights.

Debug graphics — 2/2; RelWithDebInfo unit/audio — 243/243, content — 19/19. После добавления equipment-audio сценария отдельно пересобран `relaycore_power_restoration_graphics` в RelWithDebInfo и выполнен на распакованных ресурсах. Обычные baseline compiler warnings C4834 в `pipeline_authoring_overlay_tests.cpp` оставлены без несвязанной правки.

`scripts/package-playtest.ps1` теперь сверяет authored/staged assets, копии payload и ZIP по SHA256. Внутри — `BUILD_MANIFEST.json` (revision, dirty state, digest файлов исходников, preset и 92 payload-хеша); рядом с ZIP — `.sha256`. Проверено отклонение WAV с изменённым одним байтом при прежнем размере; затем staged WAV восстановлен и его хеш сверён с source. Скрипт не компилирует executable и не заменяет предшествующую сборку. Новый dependency/tool version не требуется; штатный запуск через `pwsh` проверен. Дополнительная попытка `powershell.exe -NoProfile -File ...` не выполнялась из-за локальной ExecutionPolicy; политика не изменялась.

Архив распакован в `%TEMP%/RelayCore-standalone-...`, вне репозитория. Переменная `RELAYCORE_ASSET_ROOT` удалена только из окружения проверочного процесса, рабочий каталог — родитель распакованного пакета. Реальный `RelayCore.exe` загрузил engine/render config, atlas и power_restoration из собственной папки; OpenGL 4.6 NVIDIA 596.49, audio initialized. Проверен штатный WM_CLOSE и exit 0. Первоначальный `WaitForInputIdle` непригоден для этого console-subsystem/SDL executable; использован адресный WM_CLOSE скрытого окна с сохранённым process handle.

Для автономной проверки ресурсов тестовые executables временно скопированы рядом с распакованной игрой (в выдаваемый ZIP они не входят). Без asset override прошли:

- `relaycore_audio_lifetime.exe`: настоящий backend, декодирование боевых WAV, lifetime;
- `relaycore_content_validation.exe`: 19 cases, 816 assertions, без skips.

Все 92 payload-хеша распакованного пакета после проверок сохранились. Логи: `build/g006-release-unit.log`, `build/g006-release-content.log`, `build/g006-standalone-startup.log`, `build/profiling/relaycore_*.log`. `git diff --check` выполнен без whitespace errors.
