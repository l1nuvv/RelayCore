# RelayCore 1.3.0 — обновления из меню

- В главном меню появилась проверка новых версий и описание изменений.
- Установка скачивает и проверяет полную сборку, затем перезапускает игру.
- При неудачной установке или запуске возвращается предыдущая сборка.
- Сохранения и настройки остаются в пользовательской папке.
- Окно автоматически помещается в рабочую область экрана, если заданный размер слишком велик.

Windows 11 x64. Это тестовая сборка игрового эпизода. Для первого перехода со старой версии без кнопки обновлений скачайте и распакуйте этот архив вручную; следующие выпуски можно получать через меню. Предыдущая сборка сохраняется рядом с игрой после обновления.
