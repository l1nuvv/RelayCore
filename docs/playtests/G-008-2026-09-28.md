# G-008 — три боевых сценария на полигоне

Дата: 2026-09-28. Статус: `done` по приёмке автора.

G-007 принят автором: «полигон я проверил все ок». Этот протокол относится к следующему испытанию, включая новую смешанную встречу. После реализации автор сообщил «все ок» и попросил следующий большой блок. Точные длительности, число ручных повторов и отдельные наблюдения не предоставлены. Второе оружие реализовано следующим блоком [G-009](G-009-2026-09-28.md); приведённые ниже проверки относятся к состоянию G-008.

## Запуск и повтор

В CLion выбрать **RelayCore — Sandbox**, начать испытания. Если полигон уже открыт, F7 загружает актуальную карту и её исходное состояние. Перед подходом к выбранной угрозе нажать F9; F10 возвращает встречу вместе с игроком, здоровьем, дверями и противниками. Перед сменой сценария использовать F7, чтобы вернуть уничтоженные цели.

Тонкие полосы на полу отмечают позиции испытаний. Для проверки подготовки карты есть `level_entry`: `cover` около `(-4, 13.8)`, `rover` около `(11, 18)`, `mixed` около `(28, 19)` в координатах X/Z. `relaycore_level_check --entry` проверяет вход; игровой launcher этот аргумент не использует. Запуск из CLion читает исходные assets; сохранённая редактором пользовательская копия не заменяет карту репозитория.

## Изменения и технические проверки

- `development_sandbox.toml`: добавлена пятая турель в правой части арены, её постамент и стартовые полосы. Существующее восточное укрытие повышено до 2 м. Левый rover находится вне дальности новой турели на своей испытательной дорожке.
- `development_sandbox_tests.cpp`: грунт у всех входов, безопасный hub, уклонение от авторского замаха, защита после обнаружения, давление обеих угроз на открытой позиции, свободный выход/обход блока, уничтожение целей и три полных повтора encounter snapshot.
- `level_check_tests.ps1`: отчёт включает новую турель. `power_restoration_graphics.cpp`: три дополнительных GL-вида.

В VS developer environment с `VCPKG_ROOT` из существующего CMake cache:

```powershell
cmake --build --preset validation-debug
cmake --build --preset demo-debug --target relaycore_sandbox relaycore_level_check relaycore_power_restoration_graphics
ctest --preset validation-debug --output-on-failure
ctest --preset graphics-debug -R '^graphics\.power_restoration$' --output-on-failure
pwsh -NoProfile -File tests/level_check_tests.ps1 -Executable build/msvc-debug/src/relaygame/relaycore_level_check.exe
git diff --check
```

Результат: целевые сборки успешны; content 25/25, graphics 1/1, CLI fixtures успешны. Просмотрены `sandbox-rover.bmp`, `sandbox-mixed.bmp`, `sandbox-mixed-cover.bmp` в `build/msvc-debug/tests/power-captures`. Проверены открытый обзор новой турели и её перекрытие укрытием. MSVC-сборка выполнена вне песочницы после зависания и остановки developer environment внутри неё.

Ограничения: GL-виды и фиксированные симуляции не являются ручным проходом. Rover сохраняет прямое преследование последней видимой позиции; поиск пути вокруг сложных препятствий не добавлен. Испытательная дорожка rover и открытый участок смешанного боя не требуют такого обхода. Полный RelWithDebInfo/ASan workflow и проверка нового блока на другом ПК не выполнялись. Новая карта меняет fingerprint только сохранений полигона; файлы сохранений не удалялись, формат 3 и основной эпизод сохранены.
