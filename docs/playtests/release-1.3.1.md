# RelayCore 1.3.1 — исправление установки обновлений

- Сокращён путь временной распаковки: длинное имя папки игры больше не повторяется в нём.
- Исправлена ошибка установки, обнаруженная при полном сетевом тесте 1.3.0 на Windows.
- Проверка размера и SHA256, резервная копия и сохранения работают по прежним правилам.

Windows 11 x64. Для первого запуска скачайте и распакуйте архив в обычную доступную для записи папку. Если обновление из 1.3.0 сообщает о слишком длинном пути, закройте игру и перенесите её папку ближе к корню диска либо распакуйте 1.3.1 вручную. Сохранения находятся отдельно от папки игры.
