# VK14-11 — optional advanced GPU paths

## 11a descriptor indexing — 2026-10-14

Implemented; local correctness and selected budgets pass. Source base
`ac671fd7682a693388bc622b837ee64d1b1fc870`. `render.descriptor_indexing`
is an opt-in, prepared-renderer setting; the default remains pooled sets.
The required optional features are runtime descriptor arrays, nonuniform sampled
image indexing and partially bound descriptors. Device limits reserve the existing
pass bindings, require at least 128 material slots and cap the table at 512.
Missing features/limits select pooled sets and report that choice.

Each material has a stable slot containing five texture descriptors and three
surface vectors. Opaque instances carry their own material index, permitting
adjacent compatible geometry to batch across materials without changing order.
Transparency, overlays, viewmodels, shadow and temporal correspondence rules
remain unchanged. Separate indexed vertex/fragment variants retain the shared
shading math; the conventional interface omits the additional material varying.

The two scene slots have separate tables and surface buffers. Table updates occur
only after slot completion; no update-after-bind feature is used. Retired material
slots are released after their final scene/upload completion. Unused entries are
filled with the persistent atlas, and partially bound array semantics permit
unused descriptors in an older slot to outlive their referenced material.
Capacity exhaustion fails explicitly, including retained GPU uses. Shader reload
stages every selected variant before replacing the working pipelines.

### Performance

RTX 4060 Ti; loader 1.4.357, GPU API 1.4.329, driver `2500608000`.
`msvc-dev`, Tracy 0.14.1, validation off, warm OS/driver caches. Controls are
conventional–indexed–conventional in one process. Selected budgets: at least
10% and 0.1 ms median CPU savings under material stress; representative-view
median CPU/GPU regression at most 0.1 ms, and GPU regression at most 5%.

Stress: 4,096 visible boxes, 256 alternating materials, 640x360, SDR/MSAA1,
shadows/UI/presentation off. Each phase has 280 frames, excluding the first 40.
World views: 1280x720, HDR/MSAA4, existing directional/point/spot shadows, probes
and shotgun; fixed queues, no gameplay, audio, UI or presentation. Each phase
has 160 frames, excluding the first 40. Four-ms pacing is outside the measured
CPU scopes. CPU preparation/submission/slot waits overlap GPU work and are not
added to it. There are 2,280 GPU scene frames and 1,800 measured samples total.

## 11b meshlets and mesh shaders — 2026-10-14

Implementation and local format/parity/fallback/lifetime checks completed from
`f7fdec5`. Performance acceptance remains open; the feature stays off by default.
`render.mesh_shaders` is opt-in and requires the enabled EXT mesh-shader feature,
five descriptor sets, 32-thread groups, 64 output vertices/124 primitives,
28 output components, 12 KiB output storage and checked dispatch limits.
Missing support selects indexed rendering. Task shaders are not required.

Native RMDL v6 adds deterministic, ordered meshlets after the original payload;
v1–v5 products remain readable and original vertex/index geometry stays available. Legacy and
procedural geometry build meshlets once during GPU resource preparation.
The packer preserves exact triangle order/winding rather than reordering through
a new dependency. Reader checks cover ranges, local/global references, full
triangle coverage and exact finite bounds before GPU use.

The mesh shader rejects conservative clip-plane AABBs per instance and meshlet;
visible vertices reuse the existing transform and fragment shading. Small
single-meshlet geometry keeps the indexed path. Opaque camera/source passes use
meshlets; shadows, temporal inputs, overlays, transparency and weapons remain
indexed. The existing `gpu_culled` submission also retains its indexed command
ownership. Geometry buffers/descriptors retire under their final scene/upload
completion. Shader reload stages the optional mesh pipeline before commit.
Dispatch splitting respects X/Y/total limits and original rasterization order.

Selected before measurement: dense geometry must save at least 10% and 0.1 ms
median scene GPU time. Representative-view median GPU overhead is bounded to
0.15 ms / 10%, CPU overhead to 0.1 ms, and additional VMA allocations to 64 MiB.
The fixture compares indexed–mesh–indexed, retaining all ordinary shadows,
materials and viewmodels; the feature stays off by default.
