## Retained implementation

- `UsableSpatialIndex` owns the usable grid and its enabled/bounds snapshot.
  Unchanged spatial data reuses the grid. Movement, focus bounds, radius,
  enable/disable, insertion/removal and replacement invalidate it. The snapshot
  follows the prepared session through move/copy; it stores no runtime pointers.
  Reconstruction retains the original insertion order and focus/occlusion rules.
- Fixed simulation compares mission snapshots and builds owning presentation
  strings only when publishing a mission event. Simulation frequency, AI,
  navigation, collision and combat rules are unchanged.
- Ambient selection borrows the authored path/name while deciding the current
  source; runtime diagnostics copy the path only when it changes. Mixing,
  fades, volume, occlusion and listener updates retain their cadence.
- Local-light selection sorts in the existing active-light vector, then truncates
  to the same limit. This removes a temporary vector without changing selection
  order, lighting quality or GPU submission. Its retained capacity is bounded by
  the loaded scene's light/effect candidates; the usable snapshot by session size.

The proposed shared irradiance/reflection preparation was removed: no current
authored map uses both products. Native product/signature validation and the
existing CPU/GPU model caches remain unchanged. No new cache framework,
dependency, renderer synchronization or presentation queue was introduced.
